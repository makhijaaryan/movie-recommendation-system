# What the qualitative examples show (MovieLens 25M, seed 42)

Companion to `examples.md` (generated by `python -m src.examples`; the cases are chosen by fixed rules, not by hand). These are individual users, so each reading below is an illustration of a mechanism, and the frequencies in the table at the top of `examples.md` say how typical each situation is. A "·" in the lists means the user has no held-out rating for that movie. That is *unknown*, not a dislike, so a '·' recommendation can still be a good one.

## Successes

**S1, heavy user with mainstream taste (user 19217, 580 ratings).** Item CF (6 hits) and one-class (5) beat popularity (3), user CF (3) and MF (1). The held-out liked movies are war films, 1990s thrillers and sci-fi (*Full Metal Jacket*, *Reservoir Dogs*, *Black Hawk Down*, *Pi*), which match the drama/thriller/action history. Both neighbourhood and one-class models find them; popularity returns the same all-time list everyone gets (*Schindler's List*, *Apollo 13*, *Aladdin*).

**S2, light user with 29 ratings (user 134982).** Every rating in the history is a 1996-era drama or thriller (*Sleepers*, *Eye for an Eye*, *The Craft*, *Trainspotting*). One-class recommends *A Time to Kill*, *Phenomenon*, *Ransom*, *Primal Fear*, *Mission: Impossible*, *Eraser* and *Dead Man Walking* (2 hits). User CF also gets 2 hits, while popularity (*Forrest Gump*, *Shawshank*, *Pulp Fiction* …) and item CF (*Reservoir Dogs*, *Fight Club*, *A Clockwork Orange*) get none. With so little history the personalised models still pick up the era and genre of what this user rates, which a global popularity list cannot do.

**S3, user with unusual taste (user 101648, 365 ratings).** Comedy, action and adventure, with recent blockbusters among the held-out likes (*Deadpool*, *The Revenant*, *Django Unchained*, *Harry Potter*). One-class and user CF get 4 hits each, popularity 1 and MF 0. The one-class list is modern franchise and action fare (*Django Unchained*, *Deadpool*, *Kingsman*, *Sherlock Holmes*, *Skyfall*) while popularity and item CF return the classic canon (*Godfather*, *Star Wars*, *Schindler's List*).

## Failures

**F1, all five models get zero hits (user 61975, 72 ratings; 2.9% of sampled users).** The held-out liked movies are a scattered mix (*The Grapes of Wrath*, *My Left Foot*, *Austin Powers*, *Who Framed Roger Rabbit?*, *Dog Day Afternoon*) and share little with each other or with the history. Every model returns plausible blockbusters instead. Only five held-out liked movies exist, so "zero hits" does not mean the recommendations were bad, only that none of them happened to be among the few movies this user rated in the test split. This is a limit of evaluating against partial observations.

**F2, popularity beats one-class (user 66396; 2.5% of sampled users).** The user has three held-out liked movies, all blockbusters (*Braveheart*, *Terminator 2*, *Home Alone*). Popularity places two of them in its list, one-class one, and user CF two. The difference is one hit on three relevant items, so it is mostly noise. The strict version of this failure (popularity at least 3 hits while one-class has none) does not occur at all in the 5,000 sampled users.

**F3, MF misses where the other personalised models succeed (user 139595, 235 ratings; 2.3%).** Item CF and one-class get 4 hits, user CF 3 and MF none. MF's list is recent, mid-popularity films with no connection to the user's profile (*Spider-Man: Into the Spider-Verse*, *Guardians of the Galaxy*, *Short Term 12*, *Planet Earth II*).

## A pattern across the examples

In four of the six users (S1, S2, F1, F2) MF's top 5 contains documentaries such as *Planet Earth*, *Planet Earth II*, *The Blue Planet* or *Band of Brothers*, which have only about 500–1,400 training ratings. This matches the list diagnostics (task 6.5): ranking by predicted rating promotes rarely rated items, whatever the user's taste. That is why MF has the best RMSE and the worst top-K quality.

## Overall frequencies (5,000 sampled users)

Share of users with no hit in the top 10: popularity 59%, item CF 45%, user CF 39%, MF 73%, one-class 29%.
